### What I've Been Working On

**[VaticMacro](https://github.com/DhanushPillay/VaticMacro)** 
Built a machine learning pipeline that forecasts India's YoY inflation by processing 7 different macroeconomic indicators (like CPI and WPI). It uses a 35-feature dataset and serves predictions through a Flask dashboard.

**[LifeLink](https://github.com/DhanushPillay/LifeLink)** 
Developed a full-stack platform (React, Express, MongoDB) to help match blood and organ donors with patients. I implemented real-time presence tracking via Server-Sent Events (SSE) so users know who is online instantly.

**[Tech News Aggregator](https://github.com/DhanushPillay/Tech-News-Aggregator)** 
Wrote a Flask application that concurrently scrapes news from 5 major tech sources. I added a natural language processing layer (VADER) to analyze the sentiment of the news, and made it a Progressive Web App (PWA) so it caches data offline.

**[SmartSheti](https://github.com/DhanushPillay/SmartSheti)** & **[PixBooth](https://github.com/DhanushPillay/PixBooth)**
Created an agricultural decision support tool for farmers to get crop recommendations, and built a web-based photobooth using WebRTC for live camera access and vintage filters.
